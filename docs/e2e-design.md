# E2E Test Design: สั่งซื้อและชำระเงินสินค้าในตะกร้า

ออกแบบตาม Workshop "E2E Test using Playwright" ข้อ 1–5 สคริปต์อยู่ที่ [`tests/checkout.spec.ts`](../tests/checkout.spec.ts) ตัวช่วยเตรียมข้อมูลอยู่ที่ [`tests/helpers.ts`](../tests/helpers.ts)

## วิธีรัน

```bash
npx playwright test                 # ทั้งหมด (Playwright เปิด backend และ frontend ให้เอง)
npx playwright test checkout.spec.ts --project=chromium --ui
npx playwright show-report
```

- ต้องมี `.env` ที่มี `SUPABASE_URL`, `SUPABASE_KEY`, `JWT_SECRET` และ `E2E_PASSWORD` (รหัสผ่านของบัญชีทดสอบ)
- เทสเขียนลง Supabase จริง ก่อนทุกเทสจึงตั้งราคา stock สถานะสินค้า สถานะคูปอง ยกเลิก order ที่ค้างชำระ และล้างตะกร้าของ `cus_normal` กลับเป็นค่าตั้งต้น (`resetTestData`)
- ระหว่างรันเทส ห้ามใช้บัญชี `cus_normal` ทดสอบมือ และห้ามรันเทสสองชุดพร้อมกัน config ตั้ง `workers: 1` ไว้แล้ว
- `checkout.spec.ts` รันบน chromium อย่างเดียว เพราะเทสกฎทางธุรกิจ ไม่ขึ้นกับ browser

| DEF-06 | ไม่มีทางทำรายการชำระเงินไม่สำเร็จ | ทดสอบ OP-11 ผ่านหน้าเว็บไม่ได้ | TC-15 |
| DEF-07 | หน้าประวัติคำสั่งซื้อใช้ข้อมูลใน browser และ order ตัวอย่างที่เขียนไว้ตายตัว ไม่เรียก `GET /orders` | ไม่เห็น order จริง | TC-16 |
| DEF-08 | `POST /orders/new/payment` (OP-8) ตอบ 500 ทุกครั้ง: database ไม่รับ `zone: "bangkok"` (`new row for relation "orders" violates check constraint "orders_zone_check"`) ทั้งที่ API.md, Postman และ `SHIPPING_FEE` ใช้ค่านี้ | **checkout ผ่าน API ไม่ได้เลย** OP-8 ถึง OP-14 ใช้งานจริงไม่ได้ | TC-13, 16 (และ TC-01, 02, 14, 15 เมื่อแก้ DEF-02 แล้ว) |

ตรวจค่าที่ constraint ยอมรับได้ใน Supabase SQL Editor:

```sql
select conname, pg_get_constraintdef(oid) from pg_constraint
where conrelid = 'orders'::regclass and contype = 'c';
```

## หน้าเว็บที่ยังไม่มี: ชื่อ locator ที่เทสคาดไว้

เทสที่ ❌ ใส่ `test.fail()` พร้อมเลข defect ชุดเทสจึงยังเขียว เมื่อแก้หน้าเว็บจนเทสนั้นผ่าน Playwright จะรายงาน "expected to fail but passed" ให้ลบ `test.fail()` ของเทสนั้นออก ถ้าทำหน้าเว็บตามชื่อด้านล่าง เทสจะใช้ได้ทันที

| ส่วน | Locator ที่เทสใช้ |
|---|---|
| ช่องคูปอง (หน้าตะกร้า) | label "รหัสคูปอง" และปุ่ม "ใช้คูปอง" |
| พื้นที่จัดส่ง (หน้า checkout) | `<select>` ที่มี label "พื้นที่จัดส่ง" ตัวเลือก "กรุงเทพ" / "ต่างจังหวัด" |
| ความเร็ว (หน้า checkout) | `<select>` ที่มี label "ความเร็วในการจัดส่ง" ตัวเลือก "ปกติ" / "ด่วน" |
| สร้าง order | ปุ่มที่ชื่อขึ้นต้นด้วย "ยืนยันสั่งซื้อ" |
| หลังสร้าง order | ปุ่ม "ชำระเงินสำเร็จ", "ชำระเงินไม่สำเร็จ" และ "ยกเลิกคำสั่งซื้อ" |
